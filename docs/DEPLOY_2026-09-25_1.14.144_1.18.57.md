# Deploy 2026-09-25 — integratie 1.14.144 / worker 1.18.57

## Doel

Deze hotfix gebruikt de actuele regionale radarwaarde op de exacte positie
van ieder doel voor de huidige regenstatus. Een droge modelpuntschatting kan
daardoor niet langer een positieve regionale radarwaarde overschrijven. De
radarprojectie blijft tijdelijk in het fusieresultaat: er worden geen nieuwe
doelpersoongebonden bronobservaties in PostGIS aangemaakt.
