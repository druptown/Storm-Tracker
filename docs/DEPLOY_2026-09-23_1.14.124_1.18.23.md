# Deploy 2026-09-23 — integratie 1.14.124 / worker 1.18.23

## Doel

Maak de dunne runtime ook werkelijk onafhankelijk van de historische worker-
infrastructuur en beperk het aantal PostGIS-roundtrips:

- de radarceltrekker bouwt zijn begrensde trackingpolicy rechtstreeks op uit
  de zuivere tracking-core;
- importeren van `thin_mqtt_service` laadt geen `raw_`, `acquisition_`,
  `completion_` of `terminal_` module meer;
- alle genormaliseerde observaties van één PostGIS-write worden in één
  `executemany`-batch geschreven met behoud van dezelfde idempotente upserts.
